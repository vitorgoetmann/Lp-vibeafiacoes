# Landing Page — Vibe Afiações

Landing page comercial responsiva para apresentar os serviços da Vibe Afiações e transformar visitantes em pedidos de orçamento pelo WhatsApp.

[**Ver projeto publicado**](https://lp-vibeafiacoes.vercel.app)

## Objetivo

Criar uma experiência digital direta para um negócio local: explicar os serviços, transmitir confiança e reduzir o atrito até o primeiro contato. O orçamento é montado na própria página e enviado ao atendimento com uma mensagem estruturada no WhatsApp.

## Experiência entregue

- Hero com proposta de valor e chamada para orçamento.
- Apresentação da história e dos serviços da empresa.
- Carrossel 3D de ferramentas controlado por rolagem, arraste ou botões.
- Catálogo interativo com seleção de itens e quantidades.
- Validação de nome e WhatsApp antes do envio.
- Geração automática da mensagem de orçamento.
- Seção de horário estendido e fluxo de atendimento.
- Navegação adaptada para celular e desktop.

## Destaques técnicos

- Componentes React tipados com TypeScript.
- Estado local para carrinho, formulário e interação do carrossel.
- Integração com WhatsApp sem backend.
- Imagens reais do negócio e conteúdo orientado à conversão.
- Interface acessível por teclado e responsiva.
- Build estático leve, publicado na Vercel.

## Stack

React · TypeScript · CSS · Vite · WhatsApp Deep Links · Vercel

## Executando localmente

```bash
git clone https://github.com/vitorgoetmann/Lp-vibeafiacoes.git
cd Lp-vibeafiacoes
npm install
npm run dev
```

Validação de produção:

```bash
npm run lint
npm run build
```
